# FAISS 벡터DB 파일 검색 테스트

도로교통법 PDF를 FAISS 벡터DB에 넣고, 질문을 던져 검색 결과가 어떻게 나오는지 확인한 실습입니다.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 문서 | 도로교통법 [시행 2018. 4. 25.] [법률 제15530호] (법제처 PDF, 73쪽) |
| 벡터DB | **FAISS** (`faiss-cpu` 1.15.1), `IndexFlatIP` |
| 임베딩 모델 | `jhgan/ko-sroberta-multitask` (한국어 문장 임베딩, 768차원, 최대 128토큰) |
| PDF 텍스트 추출 | `pdfplumber` 0.11.10 |
| 실행 환경 | Python 3.13, CPU만 사용 (Windows 11) |

## 2. 처리 과정

```
PDF ─(pdfplumber)→ 줄 단위 텍스트 ─(머리말/꼬리말 제거)→ 조문 단위 분리 ─(180자 분할)→ 청크 944개
   ─(ko-sroberta)→ 768차원 벡터 ─(L2 정규화)→ FAISS IndexFlatIP 저장
질문 ─(같은 모델)→ 벡터 → FAISS에서 내적이 큰 순서로 top-k 검색
```

1. **텍스트 추출**: 쪽마다 반복되는 `도로교통법`, `법제처 N 국가법령정보센터` 줄은 제거했습니다.
2. **조문 단위 분리**: `제N조(제목)`, `제N조의M(제목)`으로 시작하는 줄을 기준으로 잘라 조문 235개를 얻었습니다.
3. **긴 조문 재분할**: 임베딩 모델은 **128토큰까지만 읽습니다.** 한글은 약 0.6토큰/글자라서 대략 200자를 넘으면 뒷부분이 버려집니다.
   그래서 줄 단위로 180자를 넘지 않게 나누고, 나눈 조각마다 앞에 `[제N조(제목)]`을 붙였습니다. 이렇게 해서 어느 조각이든 어느 조문인지 알 수 있게 했습니다.
   - 처음에는 800자로 나눴으나(청크 296개) 대부분의 청크가 잘린다는 것을 확인하고 180자로 바꿨습니다(청크 944개).
4. **인덱스**: 벡터를 L2 정규화한 뒤 `IndexFlatIP`(내적)에 넣었습니다. 정규화된 벡터끼리의 내적은 **코사인 유사도**와 같습니다.
   벡터가 944개뿐이라 근사 검색(IVF, HNSW) 없이 전수 비교(Flat)로도 즉시 검색됩니다.

## 3. 검색 결과

질문 10개를 일상적인 말투로 만들고, 정답으로 기대하는 조문을 미리 정한 뒤 top-3를 검색했습니다.

| # | 질문 | 기대 조문 | 1위 결과 | 점수 | 기대 조문 순위 |
|---|---|---|---|---|---|
| 1 | 음주운전으로 보는 혈중알코올농도 기준은? | 제44조 | 제93조(운전면허의 취소ㆍ정지) | 0.612 | 3 |
| 2 | 술 마시고 운전하면 어떤 처벌을 받나요? | 제148조의2 | 제148조의2(벌칙) | 0.684 | **1** |
| 3 | 어린이 보호구역에서 지켜야 할 것 | 제12조 | 제12조(어린이 보호구역의 지정 및 관리) | 0.754 | **1** |
| 4 | 운전 중에 휴대폰 사용해도 되나요? | 제49조 | 제49조(모든 운전자의 준수사항 등) | 0.520 | **1** |
| 5 | 고속도로에서 갓길로 달려도 되나요? | 제60조 | 제60조(갓길 통행금지 등) | 0.566 | **1** |
| 6 | 교통사고를 내면 운전자가 해야 할 조치 | 제54조 | 제29조(긴급자동차의 우선 통행) | 0.728 | 3 |
| 7 | 운전면허가 취소되는 경우 | 제93조 | 제93조(운전면허의 취소ㆍ정지) | 0.759 | **1** |
| 8 | 자전거 탈 때 헬멧을 써야 하나요? | 제50조 | 제50조(특정 운전자의 준수사항) | 0.552 | **1** |
| 9 | 주차가 금지된 장소는 어디인가? | 제33조 | 제33조(주차금지의 장소) | 0.629 | **1** |
| 10 | 긴급자동차에게 길을 양보해야 하는 의무 | 제29조 | 제29조(긴급자동차의 우선 통행) | 0.774 | **1** |

**Hit@1 = 8/10 (80%), Hit@3 = 10/10 (100%)**

질문별 top-3 원문은 [results.md](results.md)에 있습니다.

### 잘 된 점
- **단어가 달라도 뜻으로 찾았습니다.** "휴대폰"으로 물었는데 법조문의 "휴대용 전화"(제49조) 문단을 1위로 찾았습니다. 단순 키워드 검색으로는 찾기 어려운 경우입니다.
- **조문은 맞았지만 문단은 빗나간 경우도 있었습니다.** "헬멧" 질문은 1위가 제50조였지만 그 문단은 약물·전조등 내용이었고, "인명보호 장구" 문장이 든 청크는 3위였습니다. 조문 번호로만 채점하면 결과가 실제보다 좋아 보일 수 있습니다.
- 10개 질문 모두 정답 조문이 3위 안에 들어왔습니다.

### 1위를 놓친 2건 분석
- **Q1 (혈중알코올농도 기준)**: 1~3위 점수가 0.6125 / 0.6112 / 0.6106으로 거의 같았습니다. 제93조(면허 취소), 제148조의2(벌칙) 모두 "제44조 위반", "술에 취한 상태"를 반복해서 언급하기 때문에 뜻이 비슷하게 잡혔습니다.
  정답 문장(`혈중알코올농도가 0.05퍼센트 이상`)은 3위로 나왔습니다. 의미 검색은 **"0.05" 같은 숫자나 정확한 용어 일치에 약하다**는 것을 보여줍니다.
- **Q6 (교통사고 후 조치)**: 1위가 제29조(긴급자동차)였습니다. "운전자는 ~하여야 한다"처럼 의무를 말하는 문장 구조가 비슷해서 점수가 높게 나온 것으로 보입니다. 정답인 제54조는 0.009점 차이로 3위였습니다.

## 4. 발견한 문제와 개선 방향

| 문제 | 원인 | 개선 방법 |
|---|---|---|
| 숫자/정확한 용어 질문에서 순위가 밀림 | 임베딩은 의미만 비교함 | BM25 키워드 검색과 섞는 **하이브리드 검색** |
| 1~3위 점수 차이가 0.01 미만 | 법조문끼리 문체와 단어가 비슷함 | 검색 결과를 다시 정렬하는 **리랭커(Cross-Encoder)** 추가 |
| 같은 내용 청크가 2개씩 있음 (예: 제44조) | PDF에 현행 조문과 **시행 예정 조문**(`[시행일 : 2019. 6. 13.]`)이 함께 실려 있음 | 시행일 표시를 읽어서 한 버전만 남기기 |
| 단어가 줄바꿈 때문에 끊김 (예: `한 다`) | PDF 줄바꿈이 그대로 추출됨 | 줄을 합칠 때 한글 사이의 줄바꿈 제거 |
| 문서가 2018년 법 | 받은 PDF 자체가 2018년 판 | 실제 서비스라면 최신 법령으로 교체 (현행 음주 기준은 0.03%) |

## 5. 실행 방법

```bash
git clone https://github.com/SKN35shimsungwook/faiss-vectordb-file-search-test.git
cd faiss-vectordb-file-search-test
pip install -r requirements.txt
python build_index.py                     # PDF → 청크 → 임베딩 → index/ 에 저장
python search.py "음주운전 처벌" -k 5      # 직접 질문해서 검색
python run_experiments.py                 # 질문 10개 실험 → results.md 생성
```

## 6. 파일 구성

```
faiss-vectordb-file-search-test/
├─ data/도로교통법.pdf        원본 문서
├─ build_index.py            텍스트 추출, 청킹, 임베딩, FAISS 저장
├─ search.py                 저장된 인덱스로 검색 (Searcher 클래스)
├─ run_experiments.py        질문 10개 검색, 정답 순위 계산
├─ results.md                실험 결과 (질문별 top-3 원문)
└─ index/
   ├─ road_traffic.faiss     FAISS 인덱스 (944 x 768)
   └─ chunks.json            각 벡터의 원문, 조문 번호, 쪽 번호
```
